# ТЗ: Telegram-бот MWA METHOD (упрощённая версия, без e-mail)

Бесплатное 3-дневное знакомство с методом MWA через Telegram-бота.

## Путь пользователя

```
Instagram / реклама
    ↓
START (/start)
    ↓ кнопка «Начать»
WELCOME TO MWA
    ↓ кнопка «Начать»
ПРОВЕРКА ПОДПИСКИ НА КАНАЛ MWA
    ↓ (один раз, дальше не проверяется)
DAY 1 / MIND — видео → текст → практика
    ↓ 24 часа (таймер от момента отправки DAY 1)
DAY 2 / BODY — видео → текст → практика
    ↓ 24 часа (таймер от момента отправки DAY 2)
DAY 3 / ENERGY — видео → текст → практика
    ↓
ФИНАЛ → кнопка «Узнать о MWA METHOD»
```

## 1. START

Экран с описанием бота → кнопка **«НАЧАТЬ»** → переход к WELCOME TO MWA.

## 2. WELCOME TO MWA

Текст-приветствие → кнопка **«НАЧАТЬ»**.

При нажатии бот проверяет подписку на канал https://t.me/mwamethod

## 3. Проверка подписки

- **Подписан** → сразу переходит к DAY 1 (без e-mail, без доп. шагов).
- **Не подписан** → показываются две кнопки:
  - 🔗 **«ПОДПИСАТЬСЯ НА MWA»** → открывает канал
  - **«ПРОВЕРИТЬ ПОДПИСКУ»** → бот перепроверяет

Подписка проверяется **только один раз, перед DAY 1**. Дальше (перед DAY 2 и DAY 3) — не проверяется, даже если пользователь отписался.

## 4. DAY 1 / MIND

Отправляется сразу после подтверждения подписки: видео → текст → практика.

После отправки всех материалов **автоматически стартует таймер на 24 часа**. Отдельной кнопки «Завершить день» нет — день считается пройденным сразу после отправки материалов.

## 5. DAY 2 / BODY

Через 24 часа после DAY 1 бот **сам присылает все материалы целиком** (видео → текст → практика), без кнопки «Открыть День 2» и без уведомления заранее.

После отправки — снова стартует таймер на 24 часа.

## 6. DAY 3 / ENERGY

Через 24 часа после DAY 2 — аналогично, всё приходит автоматически.

## 7. Финал

Финальное сообщение + продающий текст про полную программу (6 недель / 3 эксперта / 3 направления).

Кнопки:
- **«УЗНАТЬ О MWA METHOD»** → https://mwamethod.com
- Кнопку «Присоединиться» пока не делаем.

## Важные правила логики

| Вопрос | Решение |
|---|---|
| Когда стартует таймер 24ч? | С момента отправки всех материалов текущего дня |
| Нужна кнопка «Завершить день»? | Нет |
| Нужна кнопка «Открыть День 2/3»? | Нет — приходит само |
| Повторная проверка подписки перед Day 2/3? | Нет, проверяем один раз |
| Что при повторном /start? | Прогресс не сбрасывается; бот смотрит текущий этап пользователя и либо ничего не делает, либо говорит, что следующий день придёт по расписанию |
| Если пользователь не заходил 3-4 дня? | Day 2 и Day 3 всё равно приходят по времени, не дожидаясь захода в бот |
| Повторный просмотр пройденного дня? | Отдельно не делаем — материалы остаются в истории чата |
| Видео — в чате или по ссылке? | Строго в чате бота, без внешних ссылок |
| E-mail / телефон? | Не собираем |
| Хранение данных | В базе бота: Telegram ID, username, дата старта, текущий этап (start/day1/day2/day3/final). Без Google Sheets |
| Аналитика по источникам (Instagram/Reels/реклама)? | Не нужна на этом этапе |
| Админ-панель / статистика? | Не делаем, но статусы пользователей (start/day1/day2/day3/final) желательно хранить в базе |

## Явно НЕ делаем

- Без e-mail
- Без телефона
- Без кнопок «Завершить день»
- Без кнопок «Открыть следующий день»
- Без повторных проверок подписки
- Без Google Sheets
- Без сложной аналитики
- Без админ-панели
