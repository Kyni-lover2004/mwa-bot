# Контент бота

Все тексты в формате HTML-разметки Telegram: `<b>`, `<i>`, `<u>`, `<a href="...">`.
Символы `<`, `>` и `&` в обычном тексте пишутся как `&lt;`, `&gt;`, `&amp;`.
Длина одного текста - до 4096 символов.
Разметку и длину бот проверяет при старте: если Telegram не примет текст,
бот не запустится и напишет, какой файл и что исправить.

## Экраны

- `description.txt` - описание бота «Что умеет этот бот?», которое Telegram показывает
  в пустом чате над своей кнопкой «Начать». Обычный текст без разметки, до 512 символов.
  Бот сам обновляет его при старте, в BotFather ничего менять не нужно
- `welcome.jpg` (или `.jpeg`, `.png`) - картинка экрана WELCOME TO MWA, до 10 МБ
- `welcome.html` - подпись под картинкой WELCOME, до 1024 символов (лимит Telegram для подписей)
- `not_subscribed.html` - сообщение, если пользователь не подписан на канал
- `in_progress.html` - ответ на повторный /start, пока идут дни
- `final.html` - финальное сообщение после DAY 3

## Дни

Папки `day1`, `day2`, `day3`. Файлы отправляются по порядку имени, поэтому у них числовой префикс:

- `01_video.mp4` - видео (до 50 МБ: лимит загрузки через Bot API)
- `02_text.html` - текст дня
- `03_practice.html` - практика

Поддерживаются `.html`, `.mp4` и `.fileid`. Файлы, имя которых начинается с точки, пропускаются.

## Большие видео (больше 50 МБ)

Такие видео не кладутся в репозиторий: бот отправляет их по file_id - идентификатору
файла, который уже лежит в Telegram. Размер тогда не ограничен (загрузить из приложения
можно до 2 ГБ, с Telegram Premium до 4 ГБ).

1. С аккаунта владельца или администратора канала MWA отправь видео боту в личку
   именно как видео, не «как файл».
2. Бот ответит его file_id.
3. Положи эту строку в файл `dayN/01_video.fileid` и удали `dayN/01_video.mp4`.

file_id работает только у того бота, которому отправлено видео: при смене бота видео
нужно отправить новому боту заново. Пользователи видят видео как обычное сообщение бота.

Бот загружает каждое видео в Telegram один раз и дальше шлёт его по file_id.
Первая отправка большого видео может занять несколько минут.

Контент читается при старте, после правок бота нужно перезапустить.
Новую версию видео бот узнаёт по содержимому файла и загружает заново.
Без перезапуска бот продолжит слать старую версию, а если старая ещё ни разу
не загружалась, откажется отправлять видео и напишет в лог, что нужен перезапуск.
